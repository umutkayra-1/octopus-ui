# Octopus UI

Open-source UI template gallery by [OctopusLab](https://octopuslab.tr).

Beautiful, production-ready React templates you can download and use instantly — as a developer or through your AI agent.

## Features

- Template gallery with search and category filtering
- Detailed template pages with install instructions
- AI Agent integration — skill files for Claude Code, Cursor, Copilot, etc.
- Dark theme matching OctopusLab brand identity
- Responsive design

## Quick Start

```bash
npm install
npm run dev
```

## Adding Templates

Edit `src/templates.js` to add new templates to the gallery.

## AI Agent Skill

The `skills/octopus-ui.md` file can be used by AI coding agents to automatically scaffold templates. See the `/ai` page on the site for setup instructions.
